# 3DS Macapad

A [Macapad](https://github.com/AD-Archer/Macapad) client that turns a Nintendo 3DS into a macro pad for your Mac.

<p align="center">
  <img src="screenshots/dashboard.png" width="400" alt="Top screen: clock, weather, the song playing and the Mac's CPU, memory, battery and disk. Bottom screen: a page of media keys.">
</p>

The top screen shows the time, weather, what's playing and how the Mac is doing. The bottom screen is a pad of keys
that run Mac actions, open apps and websites, press shortcuts or run Shortcuts.

You'll need [Macapad](https://ad-archer.github.io/Macapad/) running on your Mac, on the same Wi-Fi as the 3DS.

## Install with FBI

In FBI, choose **Remote Install → Scan QR Code** and scan this. It always installs the newest release.

<img src="cia/qr.png" width="160" alt="QR code for the newest macapad.cia">
